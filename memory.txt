#### B. `__init__()`

I understand:
- `__init__()` runs automatically when an object is initialized.
- It initializes the object's attributes.
- It can receive parameters.

Example:
```python
def __init__(self, path=config.DB_FILE):

    self.people = {}
```

#### C. `self`

I understand that `self` refers to the current object executing a method.

For example:
```python
self.path = path
self.people = {}
```

These attributes belong to the current object.

#### D. Instance Attributes

I understand how to access and modify object attributes.

Example:
```python
db1.people["Ali"] = [1, 2, 3]
```

- `db1` selects the object.
- `.people` accesses its dictionary.
- `"Ali"` is the dictionary key.
- `[1, 2, 3]` is its value.

Each object gets its own dictionary when initialized with `self.people = {}`.

#### E. Multiple Objects

I understand that separate objects have separate instance attributes.

I practised this using two `FaceDatabase` objects and successfully explained why modifying one object's dictionary does not automatically modify the other's.

#### F. Calling Methods Using `self`

I understand:

This calls the `load()` method belonging to the current object.

The method can access and modify that object's attributes.

I successfully completed a quiz demonstrating how changes made inside `load()` are visible outside the method through `db.people`.

#### G. Default Parameters

## Phase 2 — FaceDatabase and JSON

**Status: `load()` method studied in detail.**

I have studied the complete `load()` method:

```python
def load(self):
    if not os.path.exists(self.path):
        return

    with open(self.path, "r", encoding="utf-8") as f:
        data = json.load(f)

    self.people = {
        name: np.array(vec, dtype=np.float32)
        for name, vec in data.items()
    }
```

### A. Checking Whether a File Exists

```python
os.path.exists(self.path)
```

- Checks whether the specified path exists.
- Returns `True` or `False`.
- Does not create or read the file.

### B. `return`

I understand that `return` immediately exits the current function or method.

Here, it prevents Python from attempting to read a nonexistent database file.

### C. Opening a File

```python
with open(self.path, "r", encoding="utf-8") as f:
```

I understand:
- `open()` opens a file.
- `self.path` specifies the file location.
- `"r"` means read mode.
- `encoding="utf-8"` specifies text encoding.
- `f` represents the opened file object.
- `with` automatically closes the file after the block finishes.

### D. Reading JSON

```python
data = json.load(f)
```

I understand that `json.load()` reads JSON data from an opened file and stores the resulting Python data in `data`.

Example JSON:

```json
{
    "Ali": [1, 2, 3]
}
```

Result:

```python
data = {"Ali": [1, 2, 3]}
```

I also understand:
- `json.load(f)` reads JSON from a file.
- `json.loads(text)` reads JSON from a string.

### E. Dictionary `.items()`

I understand:

```python
data.items()
```

It provides dictionary key-value pairs.

Example:

```python
data = {"Ali": [1, 2, 3]}

for name, vec in data.items():
    print(name, vec)
```

- `name` receives the dictionary key.
- `vec` receives the corresponding value.

### F. NumPy Array Conversion

```python
np.array(vec, dtype=np.float32)
```

I understand:
- `np.array()` converts data into a NumPy array.
- `vec` is the data being converted.
- `dtype=np.float32` specifies the numerical data type.
- `np.float32` stores numbers using 32-bit floating-point precision.

### G. Dictionary Comprehension

I studied this code:

```python
self.people = {
    name: np.array(vec, dtype=np.float32)
    for name, vec in data.items()
}
```

I understand that it creates a new dictionary by looping through the existing dictionary.

The process:
1. `data.items()` provides key-value pairs.
2. `name` receives a person's name.
3. `vec` receives that person's fingerprint.
4. `np.array()` converts the fingerprint into a NumPy array.
5. `name:` becomes the key in the new dictionary.
6. The converted array becomes its value.
7. The completed dictionary is assigned to `self.people`.

I also practised understanding how to convert comprehension code into a normal `for` loop so I can understand and write it more easily.
