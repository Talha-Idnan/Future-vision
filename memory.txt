# 2. MY PROJECT

**Project name:** Future Vision

**Main files:**
- `main.py`
- `face_db.py`
- `config.py` / configuration settings
- `faces/database.json`

The project combines face recognition and general object detection.

### What the project does

1. Captures frames from a webcam using OpenCV.
2. Detects faces using MTCNN.
3. Crops detected faces.
4. Converts faces into 512-dimensional numerical fingerprints using FaceNet's InceptionResnetV1.
5. Compares fingerprints with previously saved people.
6. Identifies known people or returns Unknown.
7. Uses YOLO to detect general objects.
8. Displays bounding boxes and labels.
9. Uses LabelSmoother to reduce flickering recognition labels.

### Main libraries

- Python
- OpenCV (`cv2`)
- NumPy
- PyTorch
- facenet-pytorch
- Ultralytics YOLO
- JSON
- OS
- Collections (`Counter`, `deque`)

### Concepts already learned

**1. `os.path.exists(self.path)`**

Checks whether the specified file path exists.

Returns `True` or `False`.

It does not create or read the file.

**2. `return`**

Immediately exits the current function or method.

Here, it prevents Python from trying to read a database file that does not exist.

**3. `with open(self.path, "r", encoding="utf-8") as f`**

I understand:

- `open()` opens the file.
- `self.path` specifies which file.
- `"r"` means read mode.
- `encoding="utf-8"` specifies text encoding.
- `f` represents the opened file object.
- `with` automatically closes the file when the block finishes.

**4. `json.load(f)`**

Reads JSON data from an opened file.

For example, if JSON contains:

```json
{
    "Ali": [1, 2, 3]
}
```

Then:

```python
data = json.load(f)
```

Produces:

```python
data = {"Ali": [1, 2, 3]}
```

I understand the difference:

- `json.load(f)` reads from a file.
- `json.loads(text)` reads from a string.

**5. `data.items()`**

Returns the dictionary's key-value pairs.

Example:

```python
data = {"Ali": [1, 2, 3]}

for name, vec in data.items():
    print(name, vec)
```

Here:

- `name` receives `"Ali"`.
- `vec` receives `[1, 2, 3]`.
